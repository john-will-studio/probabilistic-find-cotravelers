# Score mover associations

1. Accept datasets and optional focal IDs; retain the population for background estimation. Identify the domain, observation process, and target behavior. Read `references/domains.md`; distinguish co-presence, coordinated movement, and interaction. Use evidence-supported labels, not presumed relationships.
2. Build tested input adapters; preserve raw data and provenance. Normalize timestamps, CRS, units, geometries, identities/deployments, altitude/depth, and error semantics. Namespace sources unless linkage is verified. Never invent IDs, accuracy probabilities, or precise timestamps from aggregates.
3. Profile deterministically: cadence/error quantiles by source/mover, missingness, coverage, gaps, duplicates, conflicts, and domain-plausible jumps. Quarantine defects. Distinguish observation uncertainty from model uncertainty; disclose unresolved semantics and informative missingness.
4. Write a dataset-specific analysis contract: dimensionality/distance metric, motion states, proximity/duration/gap scales, uncertainty model, background strata, and allowable conclusions. Infer scales from metadata/profiles and test alternatives; do not reuse human-road defaults automatically. Read `references/method.md` before using the optional local 2D CSV baseline. Adapt or replace unsupported components; abstain where evidence is inadequate.
5. Infer individual states before pairing. Index candidates with uncertainty-expanded space/time bounds; use geodesic/global indexing when required. Account for asynchronous sampling, covariance, bias, correlated errors, and outliers. Never infer sustained occupancy across unsupported gaps.
6. Classify supported shared stays, movement, arrivals/departures, visits, passing, and indeterminate events. Inspect surrounding motion and environmental constraints. Model incidental proximity at roads, ports, air corridors, or shared habitats using full-population matched controls; preserve relevant geography, season/time, cadence, and autocorrelation. Count defensible episode groups, not pings.
7. Run reproducible parallel fits: uncertainty-only, joint behavior, and background-adjusted behavior. Test domain-specific hard negatives and parameter sensitivity. Select on development data; freeze code/settings before independent holdouts. Report precision/recall by event/error/cadence, null false positives, multiplicity handling, and abstentions. After fixes, use fresh holdouts; never generalize synthetic success to untested domains.
8. Export pair/event CSVs with source/mover IDs, UTC bounds, supported duration, start/end/representative WGS84 longitude/latitude, MGRS/grid precision, altitude/depth when relevant, uncertainty, counts, episode groups, confidence (0–100), confidence kind/calibration, justified null p/q, settings/provenance, and limitations. Separate indeterminate results. Verify conversions; grid precision is not accuracy. Label heuristic scores as evidence, never interaction probabilities.
9. Write concise NYT-style analytical prose: strongest finding, dates/places, quantified support, alternatives, and limitations. Save outputs, adapters, configuration, code/source hashes, and reproducibility manifest. State which domains and capabilities were actually tested.
