# Baseline runner

Run `python scripts/analyze.py DATA.csv [MORE.csv ...] --out OUTPUT [--movers ID ...] [--link-ids] [--model C]`. Required: `mover_id,timestamp,longitude,latitude,error_radius_m,error_probability`. Require offset timestamps, WGS84 decimal degrees, meter radii. `error_probability` is enclosed spatial probability. Dependencies: existing Python, NumPy, pandas, SciPy.

The deterministic baseline profiles each source/mover, deduplicates exact observations, quarantines conflicting same-time positions, fits motion in nonoverlapping 15-minute windows, and indexes candidates with a KD-tree. A bias floor prevents unlimited precision from repeated pings. Fewer than three observations, long gaps, nonlinear trajectories, or poorly resolved speed cause abstention. Consecutive compatible windows form events; gaps/state changes break them.

Models A/B/C use uncertainty alone, joint motion, and joint motion plus local crowd correction. C discounts other movers nearby in the same time window, including unresolved motion: an empirical crowd proxy, not a road map or likelihood ratio. Confidence is a bounded heuristic evidence score. The runner does not compute null samples: orchestrate matched nulls separately. The supplied smoke benchmark includes a weekly shift diagnostic that may retain real repeated relationships. Production inference needs exchangeable controls, adequate repetitions, and multiplicity correction. Synthetic labels cannot establish real-world probability calibration.

`--movers` selects pairs containing either supplied ID; it does not specify an exact pair. Filter event outputs to both endpoints for a specific pair, and report absence as insufficient candidate evidence rather than proof of independence. CLI sensitivity flags: `--radius`, `--bias-floor`, `--crowd-radius`, and `--gap-seconds`. Freeze code hashes and settings before evaluation. Scope source identifiers by unique filenames; rename duplicate basenames before merging files.

Event times are supporting observation bounds; intervals between pings remain uncertain. Travel coordinates approximate shared locations, not route geometry. Co-dwell supports stationarity within sampled windows, not continuous occupation. Pair acceptance requires at least two days, score at least 70, and typical daily episode quality at least .4; accumulated weak evidence cannot satisfy that last requirement. Review one-off encounters separately. This baseline does not explicitly classify joint arrivals/linked visits, fit an HSMM, or support elliptical errors. Extend before claiming these.

Local tangent spatial calculations refuse spans above 1 degree and polar data. The WGS84 UTM MGRS encoder handles Norway/Svalbard exceptions and refuses UPS. Use GeographicLib/GEOTRANS for global work. Output 100-meter grids with location uncertainty separately.

References: [SciPy CDF](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ncx2.html); [NGA MGRS/UTM definitions](https://earth-info.nga.mil/index.php?action=coordsys&dir=coordsys). Proximity CDF assumes a locally flat prior and independent isotropic Gaussian errors; it is not an interaction probability.
